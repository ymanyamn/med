# التشغيل خطوة بخطوة (مواطن / مركزية / محطة / إدارة)

التطبيق واحد ورابط واحد يضم الأقسام الأربعة — لكل قسم رابطه الخاص:
`.../#/` البوابة الذكية، `.../#/citizen` للمواطن، `.../#/central` للمركزية، `.../#/station` للمحطة، `.../#/admin` للإدارة.
روابط الآيباد `#/track-...` وروابط الإدارة `#/a-...` مشفرة، لمرة واحدة، وتتجدد بعد كل جلسة —
ولا يظهر أي سر في مصدر الصفحة (الكلمات والرموز تُتحقق في الخادم فقط).
بعد النشر على Render يصبح لديك رابط
`https://med-xxxx.onrender.com` تفتحه كل الهواتف والمكاتب. بدون إنترنت يعمل من نفس
الجهاز عبر `http://localhost:3000` أو داخل شبكة واحدة عبر IP الجهاز.

## 0) البوابة الذكية — أول ما يراه الزائر
1. `.../#/` — شاشة الترحيب ثم بطاقة: «أهلاً بك — نحن ننتظر بلاغك على مدار 24 ساعة».
2. الموقع يُلتقط بصمت في الخلفية مع تجهيز القناة.
3. اكتب جملة واحدة عما يحدث → تحليل ذكي للكلمات (حريق/نجدة/انهيار/كارثة...) →
   توجيه سلس لنموذج المواطن مع تعبئة النوع والوصف تلقائياً.

## 1) المواطن — إرسال بلاغ
1. افتح الرابط. تظهر شاشة الترحيب الداكنة (العقاب + النجوم + الزخرفة).
2. انتظر اكتمال جملة «رجال الدفاع المدني معك أينما تكون» ثم اضغط «دخول».
3. تبويب «المواطن» مفتوح افتراضياً. اختر نوع البلاغ من البطاقات الخمس
   (حريق / طبي / انهيار / كوارث / عام) — أيقونات رسمية بأزرار خضراء.
4. أدخل رقم الهاتف (إجباري) + وصف الحالة (إجباري) + الاسم/المصابين/العنوان (اختياري).
5. الموقع يُلتقط بصمت في الخلفية؛ إن ظهر «تعذّر GPS» اضغط «تثبيت يدوي» ثم انقر على الخريطة.
6. اضغط «إرسال البلاغ الآن» → دائرة تحقق صامتة (موقع/أذونات/سلامة) دون إشعارات →
   «تم استلام بلاغك — ابق هنا لمشاهدة مسار البلاغ». بعد الإرسال لأقرب مركز تظهر
   بطاقة: اسم المركز + اسم مديره ورقمه للتواصل والتأكد. وتتحول الحالة تلقائياً:
   تم الإرسال ← تم الاستلام ← جارية ← مكتملة.

## 2) غرفة العمليات المركزية — الاستقبال والإرسال
1. من نفس الرابط على كمبيوتر/هاتف المكتب: `.../#/central` (تبويب «المركزية»).
2. أدخل كلمة مرور الغرفة التي سلمتك إياها الإدارة واضغط «دخول».
3. عند وصول بلاغ: بطاقة منبثقة + صوت + عداد 30 ثانية + زرّان:
   - «تأكيد البلاغ»: فتح يدوي للخريطة واختيار المحطة.
   - «الإرسال الذكي AI»: تأكيد + إسناد فوري لأقرب محطة مع مطابقة اسم المركز
     المذكور في البلاغ (يعمل تلقائياً عند انتهاء العداد للمناوب الساهي).
4. بعد التأكيد: خريطة بمعيار عملياتي + دائرة حمراء تتنفس على موقع المبلغ +
   زر «تحليل البلاغ»: تيرمينال شفاف سينمائي يكتب التحليل (الاسم/الموقع/العنوان/
   المطابقة/الأذونات/التوصية) ثم يتصغر تلقائياً.
5. اختر المحطة بالكيلومتر ← «إرسال إلى المحطة» ← مؤقت مهمة (للمركزية فقط)
   من الإرسال حتى الانتهاء + تتبع حالات الوصول والاستلام.
6. بطاقة «تتبع الفرق الميدانية»: مواقع الآيبادات لحظة بلحظة دون أجهزة GPS.

## 3) المحطة الفرعية — التنفيذ والتقرير
1. `.../#/station` (تبويب «المحطة»). اختر اسم المحطة + أدخل رمزها السري الخاص ثم «دخول المحطة».
2. تظهر فقط المهام المسندة لمحطتك. عند مهمة جديدة بحالة «مرسل» اضغط «إقرار واستلام»
   → تتحول في المركزية إلى «تم الاستلام».
3. اضغط «بدء التنفيذ» عند الانطلاق → الحالة «جارية».
4. بعد الانتهاء عبّئ: تفاصيل الحادثة + الإصابات + الموارد + ملاحظات ثم
   «إتمام المهمة + إرسال التقرير» → الحالة «منتهية» ويصل التقرير للمركزية.
5. شارة «تقارير معلقة» تنبهك للمهام المنتهية بلا تقرير.
6. «تتبع فريقي»: الصق رمز التتبع الخاص بمحطتك (من المدير) على الآيباد المرافق
   للفرقة ← «بدء مشاركة الموقع» ← تتحرك نقطة فريقك في المركزية لحظة بلحظة.

## 4) الإدارة — الدخول والإعداد (رابط مشفر + كلمة مرور)
1. `.../#/admin` ← أدخل بريد الإدارة ← «إرسال الرابط المشفر» (يصل بريدك، صالح
   30 دقيقة، لمرة واحدة، ويتجدد بعد كل جلسة عبر «إنهاء الجلسة»).
2. الصق الرابط `#/a-...` + أدخل كلمة مرور اللوحة ← «دخول اللوحة».
3. الأقسام الستة حسب المراحل: الدخول والبوابة / البلاغات / المركزية /
   المحطات والفرق (إضافة + مدير المركز ورقمه + تدوير الرمز + رابط تتبع جديد) /
   التتبع المباشر / سجل الفريق العام.
4. محرر الخريطة: اسحب أي علامة محطة إلى الموقع الجديد → «حفظ الموقع» → نشر فوري.
5. غيّر كلمة مرور المركزية من حقلها المخصص. راقب سجل المواقع الخلفية وكل الحوادث.

## ملاحظات التشغيل خارج الشبكة
- نفس الجهاز: `npm install` ثم `npm start` ثم `http://localhost:3000`.
- شبكة واحدة (Termux/واي فاي): شغّل السيرفر على جهاز، وافتح `http://IP:3000` من البقية.
- إنترنت عام: انشر على Render (ملف `render.yaml` جاهز) ووزّع رابط https.
- APK: ادفع إلى `main` في https://github.com/ymanyamn/med ← تبويب Actions ←
  حمّل MED-debug-apk وثبّته. أو من المتصفح: «تثبيت التطبيق» (PWA) بدون ملفات.
- الخرائط تحتاج إنترنت لعرض البلاطات؛ باقي التطبيق (البلاغات والحالات) يعمل
  أوفلاين عبر localStorage ويتزامن عند عودة الاتصال.
