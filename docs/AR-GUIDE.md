# دليل التشغيل والتثبيت (عربي)

## أولاً: أين توجد المركزية؟

لا يوجد تطبيق منفصل. **تطبيق واحد ورابط واحد** يضم الأقسام الأربعة:

| القسم | طريقة الدخول |
|---|---|
| المواطن | يفتح الرابط مباشرة (بدون دخول) |
| المركزية | نفس الرابط ← تبويب «المركزية» ← كلمة المرور `central123` |
| المحطة | نفس الرابط ← تبويب «المحطة» ← اختيار المحطة + رمزها (1001–1005) |
| المدير | نفس الرابط ← تبويب «الإدارة» ← البريد `redmimhmdov@gmail.com` ← كود OTP |

مثال عملي: مواطن يرسل بلاغاً من هاتفه → مكتب العمليات يفتح **نفس الرابط** على كمبيوتر المكتب
ويدخل تبويب المركزية → تصله التنبيهات لحظياً.

## ثانياً: هل يعمل على الإنترنت؟

- **على جهازك فقط (localhost):** يعمل فوراً بعد `npm start` لكن من نفس الجهاز فقط.
- **على الإنترنت للجميع:** يجب نشر الخادم على استضافة (الطريقة الموصى بها: Render مجاناً).
  بعد النشر تحصل على رابط `https://...` تفتحه كل الهواتف والمكاتب.

## ثالثاً: النشر على الإنترنت (Render — مجاني)

1. ارفع المشروع على GitHub.
2. سجّل في `render.com` ← New ← Web Service ← اربط المستودع.
3. Build Command: `npm install` — Start Command: `npm start` (ملف `render.yaml` موجود وجاهز).
4. Deploy وانسخ رابط `https://` الناتج ووزّعه.

## رابعاً: أين أكتب `npm install && npm start`؟

في أي مكان فيه Node.js، عندك 3 خيارات:

**أ) على كمبيوتر (الأسهل للتجربة):** ثبّت Node.js من `nodejs.org`، افتح Terminal/CMD داخل
مجلد المشروع ونفّذ:
```
npm install
npm start
```
ثم افتح `http://localhost:3000`.

**ب) على الهاتف عبر Termux (يحوّل هاتفك لسيرفر):**
```
pkg update && pkg install nodejs git -y
git clone <رابط-المستودع>
cd med
npm install
npm start
```
- ثم من هاتف على **نفس الواي فاي**: اعرف IP هاتف السيرفر بـ `ifconfig wlan0`
  (مثال `192.168.1.5`) وافتح `http://192.168.1.5:3000`.
- ملاحظات: ثبّت Termux من F-Droid (نسخة Play قديمة)، أبقِ الهاتف شغالاً والشاشة مفتوحة،
  وللوصول من خارج الواي فاي تحتاج نفقاً (ngrok) أو الأفضل: النشر على Render.

**ج) على سيرفر/VPS:** نفس أمرَي الكمبيوتر داخل السيرفر.

## خامساً: تثبيت APK على هواتف الأندرويد

1. ادفع الكود إلى GitHub ← تبويب Actions ← شغّل Workflow «Build MED APK».
2. حمّل ملف **MED-debug-apk** من الـ Artifacts وانقله للهاتف.
3. افتحه ووافق على «التثبيت من مصادر غير معروفة».
4. ملاحظة: نسخة debug للتجربة. النسخة الموقّعة للنشر الرسمي تحتاج keystore خاص.

**بديل أسهل من APK (يُنصح به):** افتح رابط الاستضافة في متصفح Chrome بالهاتف ←
القائمة ⋮ ← «تثبيت التطبيق / Add to Home screen» ← تصبح أيقونة MED على الشاشة
وتعمل كتطبيق (PWA) بدون أي تثبيت.
